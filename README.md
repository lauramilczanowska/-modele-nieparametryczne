# Analiza danych – predykcja transakcji kartowych za pomocą modeli predykcyjnych/klasyfikacyjnych

## Cel projektu
Celem projektu było znaleźć i zbudować najlepszy model predykcyjny/klasyfikacyjny, dla bazy danych transakcji kartowych. Głównym zadaniem modelu była predykcja czy dana transakcja rekurencyjna jest udana czy też nie. 

## Wykorzystane narzędzia
- R
- RStudio
- wykorzystane pakiety, np. 

## Zakres analizy
- Przygotowanie i czyszczenie danych
- Eksploracyjna analiza danych (EDA)
- Wizualizacja wyników
- Interpretacja najważniejszych zależności
